# PDI — Pleno → Sênior

Itaú · Squad IFA (Ion for Advisors) · Foco: AWS avançado, Terraform, System Design/Distributed Systems · Alvo: promoção a Sênior em ~2 anos + reconhecimento PRAD.

| | Objetivo para curto prazo — 6-12 meses | Objetivo para longo prazo — 12-36 meses |
|---|---|---|
| **50% Conhecimento teórico** | - Curso AWS Solutions Architect Associate (Udemy) + certificação<br>- Curso System Design / Distributed Systems (LinuxTips)<br>- Inglês técnico: ler 1 artigo/semana sem tradutor | - Certificação AWS Developer Associate<br>- Aprofundar resiliência e escalabilidade (livro/curso de referência)<br>- Inglês: participar de 1 call técnica sem apoio |
| **40% Conhecimento prático** | - Alinhar com o Tech Lead os critérios de promoção e do PRAD<br>- Criar módulo Terraform reutilizável para o squad<br>- Melhorar observabilidade (dashboard + alerta) no Datadog<br>- Escrever o primeiro documento técnico interno<br>- Fazer a primeira apresentação técnica pro squad | - Ser owner de 1 decisão arquitetural (ADR)<br>- Liderar 1 entrega ponta a ponta<br>- Fazer 4 sessões de mentoria/pairing |
| **10% Hand's on** | - PoC de arquitetura serverless com resiliência (retry + DLQ)<br>- Aplicar AWS/Terraform numa iniciativa real do roadmap do IFA | - PoC avançada de Event-Driven Architecture<br>- Propor melhoria de maturidade de IaC no time |

**Certificações-alvo:** AWS Solutions Architect Associate → AWS Developer Associate (reembolso após 1 ano de empresa).
**Rotina semanal:** dias úteis intercalando AWS / Inglês / System Design / Terraform-observabilidade (~2,5h) + fim de semana de prática (~4h).
